# 💻 Windows Optimizer (Desk PC)

Um software desktop desenvolvido com Electron para monitoramento e otimização de desempenho do computador.

## 🚀 Funcionalidades

* 📊 Monitoramento de uso de RAM em tempo real
* 🧹 Limpeza de arquivos temporários
* 🗑️ Esvaziamento automático da lixeira
* 📈 Listagem dos processos que mais consomem memória

---

## 🖥️ Interface

O sistema possui uma interface simples e intuitiva, permitindo ao usuário acompanhar o desempenho do computador e realizar limpezas com apenas um clique.

---

## 🛠️ Tecnologias utilizadas

* JavaScript
* Electron
* Node.js
* HTML5
* CSS3

---

## ⚙️ Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/Cjr-pjs/windows-optimizer.git
```

2. Acesse a pasta do projeto:

```bash
cd SEU_REPOSITORIO
```

3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm start
```

---

## 📌 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar desenvolvimento desktop com Electron, além de explorar recursos do sistema operacional como gerenciamento de memória e manipulação de arquivos.
